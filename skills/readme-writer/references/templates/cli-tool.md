# cli-tool skeleton

Use for a repository whose manifest declares a command. Write Chinese `README.md`
first using `../classification.md`; use the English headings below for
`README.en.md`, keeping the same order.

Start with the [shared centred masthead](../header-footer.md#opening). Its core
sentence says what the command does and for whom; include a measured number only
when useful and supported. Then choose the body sections below.

## Why this exists

Two to four sentences on the problem. State the alternative the reader uses
today and what it costs them. If there is a measured comparison, give the number
and the command that produced it.

## Install

```bash
<the one command that installs it>
```

State the prerequisite (runtime and minimum version) from the manifest.

```bash
<first command>
```

Show the real output, trimmed of whitespace only.
