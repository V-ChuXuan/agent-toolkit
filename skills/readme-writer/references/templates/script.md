# script skeleton

Use for a single-file or single-entry tool with no package metadata. Write Chinese
`README.md` first using `../classification.md`; use the English headings below
for `README.en.md`, keeping the same order.

Start with the [shared centred masthead](../header-footer.md#opening). Its core
sentence names the input and the output; omit badges or a logo the script does
not have. Then choose the body sections below.

## Quick Start

```bash
<the exact command, with arguments filled in>
```

Show the real output, trimmed of whitespace only. State the runtime and the one
dependency, if any.

## Usage

The arguments and what they change, as a short list or table. Include the
behaviour on bad input.

## Limitations

What it does not parse, what it silently skips, and when to use something else.

Finish with the [shared closing](../header-footer.md#closing): License,
supported Credits, and the optional Star line.
